# Bank app
This is a simple bank application written in Python that handles financial transactions and bank accounts.
The app was developed as a mean to gain practical automated testing skills.

# Notable elements
- 100% test coverage
- unit tests
- integration tests
- behaviour tests
- performance tests
- tests with mocks
- automated testing on PR with Github Actions

# Technologies
- Python
- unittest
- parameterized
- coverage
- behave
- Github Actions
- MongoDB, pymongo

# Project structure
1. The source code is located in /app directory
2. Unit, integration and performance tests are located in /app directory
3. Behaviour tests are located in /features directory
4. The workflows executed on PR with Github Actions are located in ".github/workflows" directory
